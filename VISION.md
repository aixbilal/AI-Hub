# AI Hub Vision

## Goal
Build a personal AI control centre that reduces app switching,
manual coordination, forgotten tasks, and repetitive work.

## Core responsibilities
1. Development: inspect repositories, run tests, report bugs, propose fixes.
2. Personal operations: organize goals, tasks, files, and useful reminders.
3. Business operations: review relevant communications, marketing,
   client work, and e-commerce performance.

## E-commerce boundary
The store owns its customer experience, products, checkout, and store logic.
The Hub can consume approved store data and produce combined reviews.
The Hub must remain useful even when no store is connected.

## User experience
The user communicates in natural language, reviews findings, and approves
sensitive actions. A compatible AI client is required for external chat
integration; a local MCP server alone does not provide that connection.

## Success
The system reliably saves time, identifies important work, and makes
actions understandable, reviewable, and reversible where possible.
