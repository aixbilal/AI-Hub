# AI Hub

A local-first personal AI operations system.

## Purpose
Help one person coordinate software development, personal planning,
computer/file operations, and business workflows through controlled tools.

## Product boundary
The AI Hub is the central assistant and control layer.
E-commerce remains a separate product connected through explicit integrations.

## Current stage
Initial TypeScript/MCP project. Compilation has passed, but live MCP
communication and the current server package still need verification.

## Principles
- Explain actions before implementing them.
- Start with read-only tools.
- Require approval for changes and external actions.
- Test each capability before expanding.
- Keep credentials and private data protected.
